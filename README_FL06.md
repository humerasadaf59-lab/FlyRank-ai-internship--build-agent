# FL-06 — Design Your Personal Agent

**Type:** Assignment · **Track:** General AI Fluency · **Phase:** Build (spec)

## What's here

- [`Personal_Agent_Design_Spec.docx`](./Personal_Agent_Design_Spec.docx) — the
  full 1–2 page spec for the agent, covering:
  - Job to be done
  - User and usage frequency
  - Tools and data needed, with access plan
  - Draft instructions (system prompt)
  - 5 pre-build eval cases (FL-03 style)
  - Risks and guardrails
  - Platform choice and justification (Claude Project vs. Custom GPT)

## Summary

The agent is a **Research Scout**: given a topic, it searches the web, reads
the most relevant results, and returns a concise, sourced brief — instead of
manually running multiple searches and skimming tabs. Scoped to roughly 10
build hours, as required by the brief.

See [`/FL-07`](../FL-07) for the working build based on this spec.
